# FinMate 財伴｜專題資料夾

這個資料夾已依用途整理，平常開發請從 `ai-finance-app` 開始。

## 資料夾說明

- `ai-finance-app`：目前正式的 React / Vite APP。
- `交付成果`：報告用的最終 PPT、7 分鐘講稿與備用操作影片。
- `專案文件`：目前採用的 PRD、MVP 與產品名詞說明。
- `圖片參考`：角色、配色與介面視覺參考。
- `封存`：舊版文件、舊簡報與早期 HTML 草稿，需要回顧時再開啟。

## 開啟 APP

在終端機依序輸入：

```powershell
cd "D:\上課專題\AI智能管家\ai-finance-app"
pnpm run dev
```

等待終端機顯示網址後，開啟：

`http://127.0.0.1:5173/`

若 5173 已被其他程式使用，請以終端機實際顯示的網址為準。
